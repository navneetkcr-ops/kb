# Inbox

This is the **capture bucket** — a staging area for quick thoughts, links, ideas, and AI-generated content.

## How to Use

1. **Capture anything** here without worrying about organization
2. During your **weekly review**, process each item:
   - Move to the correct domain folder
   - Add proper frontmatter (use templates from `.templates/`)
   - Or delete if no longer relevant
3. Goal: **inbox zero** by end of each weekly review

## When Copying from Web AI (Gemini, Claude.ai)

Paste the AI-generated markdown here, then file it during your next review session.
